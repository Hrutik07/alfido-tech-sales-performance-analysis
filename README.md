# Alfido Tech — Sales Performance Analysis

This repository contains a Python/Jupyter analysis of the supplied Superstore sales dataset.

## Files
- `Alfido_Tech_Sales_Performance_Analysis.ipynb` — reproducible analysis and charts.
- `Alfido_Tech_Sales_Performance_Summary.pdf` — dashboard-style PDF summary.
- `data/superstore_sales_data.csv` — normalized dataset copy supplied for this analysis.

## Run
Install: `pandas numpy matplotlib seaborn jupyter`

Open the notebook from this folder and run all cells. The notebook reads `data/superstore_sales_data.csv`.

## Scope note
The supplied data has Sales but no Profit, Cost, Discount, web sessions or conversion events. Revenue and AOV are calculated; profit margin and conversion rate are not available. Low sales is not treated as proof of low profitability.
